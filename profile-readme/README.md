## Simarium — built for myself

Built and operated solo. Each tool runs a real model of the system it teaches — the Git visualizer executes merge, rebase and cherry-pick against an actual commit graph rather than replaying a scripted animation. Everything runs client-side against simulated state, so there is no backend to keep alive.

- **Git Visualizer** — live. Run add, commit, merge, rebase and cherry-pick against a modelled repository and watch the commit graph respond.
- **JavaScript Internals** — partly live. Event loop and array node canvas are live; the rest of the runtime model is in progress.
- **AWS Playground** — in progress. Cloud primitives as manipulable objects rather than console screenshots.
- **Kafka Playground** — in progress. Producers, partitions and consumer groups you can push events through.
- **Web Communication** — in progress. HTTP, WebSocket and the transports between them, side by side.
